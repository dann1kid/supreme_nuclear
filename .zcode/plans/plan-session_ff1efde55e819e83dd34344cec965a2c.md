# Этап A «тестовый комфорт» UI — v0.32.0

Цель: снизить стоимость каждого плейтеста. Миникарта — плавающее опциональное окно в духе SupCom (стратегический зум остаётся главным инструментом обзора).

## 1. UiKit — каркас построителя UI (новый `UiRts/UiKit.cs)
- `FloatingWindow`: заголовок-drag, resize за правый нижний угол, кнопка закрытия; свёрнутое окно восстанавливается через мини-вкладку на краю экрана (селектор). Позиция/размер/видимость сохраняются в BepInEx-конфиг.
- `ScrollList` (viewport + content + VerticalLayoutGroup + scrollbar), `ProgressBar` (заливка Image), простой `Tooltip` (общий объект, панели кормят текстом при наведении).
- Глобальный `Settings.UiScale` (0.75–2.0) — применяется к referenceResolution канваса SupcomUi (масштаб всех панелей разом).

## 2. Миникарта (новый `UiRts/MinimapPanel.cs`, компонент от плагина)
- Фон: `MapSettings.MapImage` (готовый спрайт карты, разведка подтвердила; фолбэк — тёмная заливка), границы карты через существующий `GameApi.TryGetMapBounds`.
- Иконки: пул `Image` (словарь Unit→Image, prune мёртвых), обновление позиций 10 Гц: свои зелёные, враги по разведке (`GetTrackingData`, тающие серые по давности — как в IMGUI-иконках), ракеты мигающие, аэродромы ромбами, месторождения жёлтые, экстракторы цветом владельца.
- Рамка текущего обзора камеры: 4 угла экрана → луч в землю → координаты миникарты, 10 Гц.
- ЛКМ по миникарте — прыжок камеры (`CommanderCameraState.CenterOn`); ПКМ — приказ выделенным в точку (обычный/Shift-очередь), враги не пикингуются (v1).
- Всё внутри `FloatingWindow`: перетащить/ресайз/закрыть/вернуть; указатель над окном = `PointerOverUi` (существующий EventSystem-механизм уже гасит игровые клики).

## 3. Панель свойств выделения (в `SupcomUi`, левая колонка над ростером)
- Один юнит: имя (`unit.unitName`), тип/роль (`vehicleType`/`roleIdentity`), HP-бар (агрегат `partLookup`-hitPoints, данные разведки), скорость (`unit.speed` → `UnitConverter`), высота (`radarAlt`), топливо (`Aircraft.GetFuelLevel()`), состояние AI (`pilots[0].GetCurrentState()` — читаемая строка), вооружение (`weaponStations`: имя/патроны/перезарядка), текущий приказ + очередь сегментов с цветами режимов (данные уже в `AircraftOrders`/`GroundOrders`).
- Мультивыделение: средний HP, средний боезапас (`GetAmmoLevel`), состав по типам (уже в ростере).
- Обновление 0.2 с (как остальной SupcomUi), перестройка по хэшу.

## 4. Списки покупок (контекстная панель SupcomUi)
- Скролл через `ScrollList`, полный каталог (сейчас обрезан 12 позициями), группировка техники по `VehicleType` с заголовками групп.

## 5. HP над повреждёнными юнитами (`CommanderHud`)
- Полоска ~26×3 px над якорем юнита, только при hp < 99.5%, зелёный→красный.
- Кэш HP-долей в `GameApi` (обновление 5 Гц, `partLookup.Average` — аллокация только в кэше, OnGUI чистый).

## 6. Settings + версия
- Новые: `UiScale`, `MinimapEnabled` + позиция/размер/видимость (персист).
- `PluginInfo` → 0.32.0. Сборка обязана остаться 0 ошибок / 0 предупреждений, автодеплой.

## 7. Синхронизация документации (по правилам AGENTS)
- ARCHITECTURE §2 (новые UiKit/MinimapPanel), §8 (раскладка UI, плавающее окно, сводка кликов миникарты), §12 (без новых долгов; тултипы-полировка — этап D), память проекта.

## Замечания по рискам
- `MapSettings.MapImage` может отсутствовать на кастомных картах — фолбэк на заливку + рамка границ.
- Патроны `weaponStations` на клиенте обновляются по событиям (в сингле/хосте точно; клиенту — как есть, без `CmdAskAmmo` в v1).
- `unit.speed` у наземки знаковый (задний ход) — отображать модуль.
