# units.bundle — китбаш-контент юнитов (свои модели поверх нативных префабов)

Игра: Nuclear Option, **Unity 2022.3.62** (тот же проект, что для `splat.bundle` —
см. `splatshader/README.md`). Мод работает и без бандла (различие тиров — тинтом);
бандл добавляет собственные меши: надстройки/краны/корпуса **поверх нативного
префаба** — физика, сеть, части урона и руление остаются нативными, ничего не ломается.

## Что моделировать

Каждый «набор пропсов» — GameObject, чьи дети — твои меши в **локальных
координатах донора** (ставится дочерним объектом юнита при спавне). Донор
виден всегда — моделируй надстройки, а не весь корпус: T2 — кран/контейнеры,
T3 — тяжёлый широкий корпус/модули. Ориентация донора: +Z — вперёд.

Точные габариты доноров мод печатает в `BepInEx/LogOutput.log` при старте
(строка `Engineer: клоны созданы — … (доноры Truck2-T Д×Ш×В м / LandingCraft1 …)`)
— сверь модель по ним. Проще: в Blender собери блоки по габаритам, экспортируй,
подгони по скриншоту из игры.

## Ключи-наборы (v0.150)

| Ключ | Юнит | Донор (префаб нативный) |
|---|---|---|
| `SN_ENG_T2_LAND` | Инженер T2 (депо) | грузовик TRUCK |
| `SN_ENG_T3_LAND` | Инженер T3 (депо) | грузовик TRUCK |
| `SN_ENG_T2_SEA` | Морской инженер T2 (верфь) | катер LC (ховер-амфибия) |
| `SN_ENG_T3_SEA` | Морской инженер T3 (верфь) | катер LC (ховер-амфибия) |

Ключи расширяемы: новые `SN_*` — добавь имя в `Editor/BuildUnitsBundle.cs`
и обработай в моде (сейчас ключи зовёт `EngineerService.Decorate`).

## Сборка (один раз, ~10 минут)

1. Тот же Unity-проект, что для сплата (2022.3.62, Universal 3D) — или новый.
2. В `Assets/` проекта: папка `unitcontent/`, в неё — FBX/меши из Blender.
3. Собери набор: пустой GameObject с именем РОВНО как ключ (например
   `SN_ENG_T2_LAND`), дети — меши; сохрани как префаб
   `Assets/unitcontent/SN_ENG_T2_LAND.prefab`. Материалы — URP/Lit.
4. Скопируй `Editor/BuildUnitsBundle.cs` в `Assets/Editor/`.
5. Меню **Supreme Nuclear → Build units.bundle** → в корне проекта `units.bundle`.
6. Положи в `BepInEx/plugins/SupremeNuclear/` игры.

## Проверка в игре

Перезапуск, построи инженера T2. В `BepInEx/LogOutput.log`:

```
UnitContent: бандл юнит-контента загружен — N ассетов
Engineer: клон ИНЖ2 задекорирован (HP ×2.67, пропсы)
```

Нет этих строк и написано «units.bundle не найден» — бандл не доложили;
«клон … задекорирован (HP ×2.67)» без «пропсы» — ключ с другим именем
(проверь имя префаба = ключу).

## Лицензия

Только собственные модели или CC0/совместимые. Меши/текстуры Supreme Commander
(GPG/Square Enix) использовать НЕЛЬЗЯ — как и код GroundControlRts (AGENTS.md).
«По духу SupCom» (силуэт/пропорции) — можно, конкретные ассеты — нет.

## Технические детали

- Загрузчик — `src/SupremeNuclear/Units/UnitContent.cs`: `AssetBundle.LoadFromFile`
  один раз за запуск, кэш по ключу (null тоже кэшируется — отсутствие не спамит лог).
- Прививка — `EngineerService.Decorate` после спавна (депо — скан реестра,
  верфь — ссылка из `NavalDock.TryLaunch`): `Instantiate(prefab, unit.transform,
  worldPositionStays: false)` — локальные координаты сохраняются.
- Пропсы — host-локальный визуал (как тинт): MP-клиенты не увидят (долг §12-58а,
  SP-first). Коллайдеры в набор НЕ добавляй — только меши/эффекты.
