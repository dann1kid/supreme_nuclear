# Supreme Nuclear (RTS)

RTS-мод в духе Supreme Commander для игры Nuclear Option.
Дизайн игры — [DESIGN.md](DESIGN.md) · устройство кода — [ARCHITECTURE.md](ARCHITECTURE.md) ·
правила внесения изменений — [AGENTS.md](AGENTS.md).

## Что уже есть (v0.58)

- **Каркас** BepInEx-плагина; Harmony-патчей ровно два (руление авиации с приказом,
  стойка «не открывать огонь») — оба с честным откатом к штатному поведению.
- **Камера «взгляд из космоса»** (SupCom): СКМ — «схватить и тащить» карту (скорость 1:1
  масштабу сцены), колесо — зум к курсору в обе стороны (до «вся карта в кадре», облака выше
  15 км скрываются), издалека — вид сверху, вблизи угол — Space+ЛКМ, edge-scroll, Home — центр.
  Floating origin зафиксирован на время режима (без дрожи мира).
- **Выделение**: клик, рамка, двойной клик — все юниты типа на экране; группы управления
  Ctrl+1..9 / 1..9 (дабл-тап — камера на группу); клик по зданию аэродрома — выбор аэродрома.
- **Приказы** (ПКМ, Shift — очередь): движение решёткой-формацией, атака-движение, атака
  по цели (авиация), патруль, стоп; drag-редактирование вейпоинтов прямо на карте,
  снап постановки к юнитам; ПКМ по вейпоинту борта превращает сегмент в патруль.
- **Авиация**: планы полётов сегментами, профили высот Alt+1/2/3 (150 м AGL с огибанием
  рельефа / 800 м / 2500 м), руление — игровой автопилот (`AutoAim`), attack-move сам
  вступает в бой и продолжает план; маршруты рисуются лентами по рельефу.
- **Экономика v1** (хост): месторождения (авторазметка или JSON-профиль) + захватываемые
  экстракторы с тиями T1–T3 и апгрейдами, тиковый доход во фракционные деньги.
- **Покупки**: техника через депо, авиация через аэродром (панель по клику).
- **Стройка где угодно**: инженеры (грузовики/Jackknife), каталог с тирами, shift-серии,
  единая очередь инженера по порядку кликов, кольцевой подход и стоп-затем-строй,
  недострои с достройкой ПКМ, 3D-призраки (силуэты, драг за тело), Ctrl+K — снос.
- **Фабрики с очередями**: депо и аэродромы — потоковая оплата, пауза/цикл, ралли-маршруты,
  отмена позиций, стак плиток с прогресс-баром.
- **Шаблоны** («Ш»): персистентные JSON-наборы с относительными позициями зданий.
- **Групповое управление**: групповые вейпоинты (один маркер на приказ, драг/удаление
  на формацию), shift+клик/рамка — добавление в группу.
- **UI**: SupCom-раскладка (вкладки/ленты/контекст-кнопки), стратегические иконки с
  развед-гейтом, HP-полоски, плавающая миникарта, F11 — отладка.
- **Инфраструктура**: конвейер `tools/build.py` (линт + тесты + контроль версии/деплоя
  байтами), тест-раннер чистой логики.

## Сборка

```bash
python tools/build.py   # конвейер: пересборка (предупреждения = ошибки) + линт + тесты + проверка версии
```

По умолчанию DLL автоматически копируется в
`C:\Program Files (x86)\Steam\steamapps\common\Nuclear Option\BepInEx\plugins\SupremeNuclear\`.
Иная установка игры: `dotnet build -p:GameDir="X:\...\Nuclear Option"`.
Без деплоя: `-p:Deploy=false`.

Требуется .NET SDK (пакет reference-сборок net472 подтянется NuGet'ом автоматически).

## Тест в игре

1. Запусти Nuclear Option (BepInEx 5 — уже стоит вместе с Ground Control).
2. Любая миссия с наземными юнитами (например, миссии Ground Control или своя из редактора).
3. Выйди из кабины (камера свободная) → **F10** — режим командира, **F10** — выход.
4. Горячие клавиши: ЛКМ — выделение/рамка/перетаскивание вейпоинтов, ПКМ — приказ
   (Shift — серия), M/A/U/T/S — режимы, H — огонь удерживать, Ctrl+1..9 — группы,
   Alt+1/2/3 — профиль высоты авиации, СКМ/колесо/Space+ЛКМ — камера, F11 — отладка.

Настройки: `BepInEx/config/com.supremenuclear.rts.cfg`.
Баланс экономики: `BepInEx/plugins/SupremeNuclear/Economy/<профиль>.json` (образец создаётся сам).

## Структура

```
src/SupremeNuclear/
  SupremeNuclearPlugin.cs    — точка входа BepInEx (Harmony, sceneLoaded, компоненты)
  CommanderModeController.cs — режим командира: единственный тик-оркестратор
  CameraRts/                 — CommanderCameraState (стратегическая камера, без патчей)
  Input/                     — RtsInput: сырой ввод с защитой от чата
  Selection/                 — клик/рамка/дабл-клик/группы
  Orders/                    — OrderModes, MoveOrderService, GroundOrders, RouteEditor,
                               RouteRibbonMesh (эксперимент)
  Aviation/                  — AircraftOrders (планы полётов), AircraftSteeringPatch
  Economy/                   — EconomyService (host), EconomyProfile (JSON-баланс)
  Units/                     — PurchaseService, StanceService, TurretHoldFirePatch
  Ui/                        — CommanderHud (IMGUI-оверлей: иконки/маршруты)
  UiRts/                     — SupcomUi (uGUI-панели)
  Core/                      — Log, Settings, GameApi, SelfCheck, PluginInfo
decompiled/                  — декомпилированная игра (справочник API)
GroundControlRts/            — бета Ground Control (только референс, не копировать)
```
