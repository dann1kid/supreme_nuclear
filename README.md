# Supreme Nuclear (RTS)

RTS-мод в духе Supreme Commander для игры Nuclear Option.
Дизайн игры — [DESIGN.md](DESIGN.md) · устройство кода — [ARCHITECTURE.md](ARCHITECTURE.md) ·
правила внесения изменений — [AGENTS.md](AGENTS.md).

## Языки / Languages

Интерфейс мода локализован: **русский** (основной) и **английский** — настройка
`General.Language` в `BepInEx/config/com.supremenuclear.rts.cfg` (`auto` — язык системы,
принудительно `ru`/`en`; применяется при запуске). Добавить свой язык — один файл
`BepInEx/plugins/SupremeNuclear/Locales/<язык>.json` по образцу `en.json` (см. AGENTS
«Правила локализации»). Диагностика (логи, SelfCheck, F11) — только по-русски.

The mod UI ships in **Russian** (source language) and **English** — set
`General.Language` in the BepInEx config (`auto` follows your OS language). New locales
are a single JSON file; untranslated entries fall back to English, then Russian.

## Установка (для игрока)

1. Установи BepInEx 5 в Nuclear Option (если ещё нет — так же, как для Ground Control).
2. Скачай `SupremeNuclear-<версия>.zip` из [релизов](../../releases) и распакуй в
   `Nuclear Option/BepInEx/plugins/` — должна получиться папка `SupremeNuclear`
   с DLL и `Locales/`.
3. В игре: выйди из кабины → **F10** — режим командира. Горячие клавиши — раздел
   «Тест в игре» ниже.

Сборка из исходников — раздел «Сборка» ниже.

## Quick start (English)

SupCom-style RTS layer on top of Nuclear Option: strategic camera, box selection,
waypoint orders (queues, patrols, attacks, escort), build-anywhere engineers,
factories with production queues (depot / airbase / naval yard), economy, weapon
gates, aircraft loadouts. UI ships in English and Russian (`General.Language` in
the BepInEx config). Leave the cockpit and press **F10** for commander mode.
Controls/UX feedback is welcome — GitHub Issues (feedback template).

## Что уже есть (v0.98.1)

- **Каркас** BepInEx-плагина; Harmony-патчей ровно пять (руление авиации с приказом —
  самолёты и вертолёты, пиннинг цели приказа — самолёты и вертолёты, стойка «не
  открывать огонь») — все с честным откатом к штатному поведению.
- **Камера «взгляд из космоса»** (SupCom): СКМ — «схватить и тащить» карту (скорость 1:1
  масштабу сцены, без лага сглаживания), колесо — зум к курсору в обе стороны (до «вся карта
  в кадре», облака выше 15 км скрываются). Наклон — одна гладкая кривая по зуму: из космоса —
  вид сверху, при подъезде к поверхности плавно и слегка ужесточается до крутого взгляда в землю
  (горизонта в обычной игре не видно). **Space (зажать) — осмотр**: мышью крутишь вид вокруг
  точки в любую сторону, включая горизонт; отпустил — камера возвращается (удобно снова обводить
  войска). edge-scroll, Home — центр.
  Floating origin зафиксирован на время режима (без дрожи мира); эффект Доплера гасится
  (камера летает на скорости в тысячи м/с — без этого звук «пилит» уши; настройка
  `Audio/CommanderNoDoppler`, вне режима звук штатный).
- **Выделение**: клик, рамка, двойной клик — все юниты типа на экране; группы управления
  Ctrl+1..9 / 1..9 (дабл-тап — камера на группу); клик по зданию аэродрома — выбор аэродрома.
  Инфопанель группы показывает сводку вооружения: чем работать по целям (теги АА/АЗ/У,
  ядерное — «Я»), заряд/ёмкость по группе и число носителей (две станции на одном борту —
  один носитель), расстрелянные типы помечены «пусто»; грузовые/десантные станции не считаются.
- **Кольца дальности (SupCom)**: у выделенных юнитов рисуются кольца **атаки по наземным**
  (красное) и **по воздушным целям** (синее — максимум дальности станций соответствующего
  домена, разрешённых гейтами вооружения), **разведки** (белое — радар/визуальный детектор
  юнита) и **стройки** (охристое — инженерный радиус площадки). Рендер как в SupCom:
  векторные полилинии в мире (ломаная видна вблизи), прибиты к земле идеально и не
  нагружают кадр; вблизи камеры кольца следуют мешу поверхности точными высотами,
  на стратегическом зуме — сглаженный кэш; видны сквозь сопки (абстракция
  стратегического слоя). Переключатели
  «Назем / Воздух / Разведка / Стройка» — чипы под миникартой (цвет чипа = цвет колец);
  всё выключить — «кинематографичный» экран без колец, выделение остаётся. Режим
  **«Оружие»** (чип под миникартой): вместо доменных колец атаки — кольца по классам
  вооружения (пушки жёлтые / ракеты ВВ синие / ракеты АС красные / бомбы и ЯЗ
  фиолетовые), только по классам, разрешённым гейтами — выключил «Рак.АС» и видно,
  что осталось (например, пушечный выхлоп из-за холма).
- **Осмотр чужих целей**: ЛКМ по видимому вражескому/союзному юниту, зданию или летящей
  ракете/бомбе — инфопанель разведки (HP/скорость/высота под живым наблюдением, возраст
  протухшего контакта; у ракет — двигатель, ГСН, БЧ и наша ли цель у ГСН). Видимость —
  как у иконок: без разведки чужой не «прощупать», ракеты видны обеим сторонам; панель
  гаснет, когда цель погибла или ушла из разведки.
- **Приказы** (ПКМ, Shift — очередь): движение решёткой-формацией, атака-движение, атака
  по цели (авиация и наземка/флот; Shift+ПКМ по целям — серия: цели выполняются по
  порядку, у наземки/флота — очередь целей), патруль (авиация и наземка/флот: цикл
  точек, ноги с боем; инженеры в патруле сами достраивают близлежащие недострои и
  возвращаются в маршрут), залп, стоп;
  drag-редактирование вейпоинтов прямо на карте, снап постановки к юнитам;
  ПКМ по вейпоинту превращает сегмент плана борта в патруль, а маршрут наземки/флота —
  в цикл.
  **Сопровождение/ассист (ПКМ по союзному юниту)**: боевые следуют за целью своим
  сектором (группа распределяется веером вокруг), рядом с целью защищают её —
  стоп-энд-файр (флот дерётся на ходу); **движение — плавно по следу цели**:
  якорь эскорта скользит по сплайну (Catmull-Rom) её траектории на дистанции
  позади — колонна повторяет маршрут цели без рывков; цель встала — охрана
  собирается кольцом вокруг; инженеры сопровождают и **вливаются в стройки
  цели** — достроили её площадку и вернулись к сопровождению; авиация сопровождает
  полётом (держится у цели, враг в дальности вооружения — нативный бой; Shift+ПКМ —
  дописать эскорт в план). Связь видна зелёной лентой к цели; Ctrl+Shift+ПКМ по цели
  снимает сопровождение у всех, S/новый приказ — как обычно. Наземке сопровождение
  в очередь не ставится (только новый приказ).
  Наземка своих едет к цели напрямую (SupCom-стиль), не заезжая на шоссе ради коротких
  перегонов; если прямая пересекает воду — маршрут строится по-нативному, через мосты
  (отключается: Orders → GroundDirectRouting в конфиге).
  Панель команд контекстная: состав кнопок — по типам войск в выделении (авиация получает
  ряды высоты/скорости/защиты и чипы станций, наземка — только применимые приказы);
  внизу карточки — гейты вооружения: кнопки ЯД/Бомбы/Пушки/Рак.ВВ/Рак.АС (по составу
  выделения) выключают класс оружия всему выделению — выключенный класс не применяется
  ни автоогнём, ни в явной атаке/залпе; подсветка — зелёный/красный/жёлтый.
- **Атака по цели = гарантированный огонь доступными средствами**: борт пиннится на
  указанную цель (стройка цели в бой — нативный AI игры), подлетает к ней по даталинку
  (нет контакта — к точке клика, сенсоры захватят по пути); ракетный залп нативно
  распределяется по соседним целям. Атака-движение — конусом по вектору приказа.
  Боезапас/топливо конечны: «сухой» борт уходит на базу, перевооружается/заправляется
  (аэродромный сервис за деньги) и повторяет вылет, пока цель жива. Наземка дерётся
  на ходу нативными турелями; атака-движение наземки — стоп-энд-файр (заметил → встал →
  расстрелял → поехал дальше), атака цели — подход на дальность вооружения.
- **«На базу» (G) = возврат в резерв ангара**: выделенные борта — пачкой или поодиночке,
  самолёты и вертолёты — возвращаются на ближайший подходящий свой аэродром, садятся,
  обслуживаются (перевооружение/заправка за деньги) и уходят **в резерв ангара**
  (деспавн): не занимают полосы и не висят мёртвым грузом. Выкат — плиткой «РЕЗ ×N»
  в панели аэродрома (бесплатно, борт выкатывается из ангара и взлетает). Резерв
  привязан к базе и теряется вместе с ней при захвате. Боевой авто-возврат
  («сухой» борт) остаётся физическим: сел → обслужился → взлетел → продолжил вылет.
- **Залп по нескольким целям (V)**: ПКМ по цели — подлёт и одновременный пуск выбранных
  ракетных станций (распределение по соседним целям — нативное, расход по потребности,
  потолок ракет на цель — настройка); ПКМ по земле — залп по площади у точки;
  Shift+ПКМ по целям — дописать цели в один залп («разом по нескольким»). Выбор
  вооружения — чипами станций на панели (одиночный борт). Бомбы/пушки — нативный бой.
  После залпа «сухой» борт сам идёт на перевооружение и продолжает план.
- **Атака веером (R)**: выдели группу атакующих, заряди R, ПКМ по врагам накапливает
  цели (фиолетовые кресты с номерами), ПКМ по земле — группа распределяется по целям:
  каждый — к ближайшей цели со свободной ёмкостью, цели получают атакующих поровну
  (N/M, лишние — первой цели по порядку клика). Работает для авиации и наземки/флота
  вместе; инженеры не воюют.
- **Disperse Move (Alt+Shift+R)**: поставь группе серию вейпоинтов через Shift как
  обычно, нажми Alt+Shift+R — очередь распределяется: каждый юнит получает ОДИН вейпоинт
  (порядок кликов, i mod G) и летит прямым вектором (FAF-стиль, разведка веером).
  Наземка и авиация распределяются каждая по своей очереди.
- **Режимы полёта на участок маршрута**: высота Alt+1..4 (Сверхнизко 75 м с огибанием
  рельефа / Низко 150 м / Средне 800 м / Высоко 2500 м) и скорость Shift+1..3 (Полный /
  Крейсер / Эконом — только самолёты; вертолётам доступна высота, тротл ведёт игра).
  «Вдоль рельефа» Alt+T — авто (по профилю: низкие огибают, средние/высокие — нет) →
  огибать → напрямую; действует на самолёты (вертолёты огибают рельеф всегда).
  Режим на момент клика штампуется на участок; смена посреди Shift-серии режет новую
  ногу маршрута; переключение при выделенных бортах меняет текущий участок немедленно.
- **Авто-защита бортов**: «Авто» (по умолчанию) — при ракетном предупреждении борт
  уклоняется нативно (нотчинг/манёвр увода, ловушки и джаммер по типу ГСН) и продолжает
  план; «Ловушки» — маршрут держим, контрмеры автоматически; «Выкл» — прорыв.
  Alt+D — цикл по выделению, X — ручной сброс ловушек.
- **Авиация**: планы полётов сегментами, руление — игровой автопилот (`AutoAim`),
  attack-move сам вступает в бой и продолжает план; маршруты рисуются лентами по
  рельефу, углы вейпоинтов скруглены (радиус — Routes/RouteCornerRadiusM). Вертолёты и
  тильтвинги исполняют приказы наравне с самолётами (своя перегрузка автопилота,
  вертикальная посадка в цикле вылета).
- **Экономика v1** (хост): месторождения (авторазметка или JSON-профиль) + захватываемые
  экстракторы с тиями T1–T3 и апгрейдами, тиковый доход во фракционные деньги.
- **Покупки**: техника через депо, авиация через аэродром (панель по клику).
- **Стройка где угодно**: инженеры (грузовики/Jackknife), каталог с тирами, shift-серии,
  единая очередь инженера по порядку кликов, кольцевой подход (инженеры окружают
  призрак веером и останавливаются вне габарита здания) и стоп-затем-строй,
  недострои с достройкой ПКМ по призраку/маркеру (Shift — дописать в очередь),
  3D-призраки (силуэты, драг за тело), Ctrl+K — снос.
- **Флот и верфь** (v0.92): платформа-верфь на воде в духе SupCom — инженеры строят
  её посреди бухты (плавучий Jackknife «барахтается» вплавь к площадке), готовая
  верфь — третья фабрика: очередь кораблей с потоковой оплатой, тиры по цене
  (T1 катера → T3 авианосцы), спуск кольцами в свободную воду с проверкой глубины
  и габарита, ралли-маршруты как у депо; корабли (8 типов, включая палубные
  Hyperion CV с финишером и Annex LHA) водятся общим контуром приказов.
- **Фабрики с очередями**: депо и аэродромы — потоковая оплата, пауза/цикл, ралли-маршруты,
  стак плиток с прогресс-баром. Плитки читаемые: короткая подпись борта (`code`),
  бейдж типа слева-сверху (авиация — индивидуальный силуэт как на макрокамере и роль
  И/У/М; наземка — ТНК/ББМ/АРТ/ЗРК/… по классу), у плиток каталога — цена; наведение
  на плитку переключает левую панель свойств в карточку закупки (имя, класс/роль,
  цена и время, ТТХ — обзор/скорость/броня/экипаж, вооружение) и открывает окно
  «ОПИСАНИЕ» под ней. **Лодауты заказов**: колесо мыши над плиткой авиации в каталоге
  циклит пресеты (Стандарт → именованные; выбор липкий по типу борта, плитка
  помечает отступление «·ЛN», карточка пересчитывает вооружение и показывает
  недоступные пресеты). **СКМ по плитке** — окно «ОСНАЩЕНИЕ»: пресеты, топливо,
  станции с клик-циклом вариантов (правки = пресет «Свой» в общем цикле), масса
  подвесок и легальность на аэродроме. Клики по стаку
  очереди: ЛКМ — +1, ПКМ — −1 с возвратом денег, Shift — ±5.
- **Шаблоны** («Ш»): персистентные JSON-наборы с относительными позициями зданий.
- **Групповое управление**: групповые вейпоинты — свойство приказа, а не выделения
  (один маркер на приказ у всей группы, драг/удаление двигают всех — выделять
  всю группу не нужно); маршрут группы — одна магистраль от центра юнитов через
  точки приказов, индивидуальные приказы — личные ветки схождения/расхождения;
  shift+клик/рамка — добавление в группу.
- **UI**: SupCom-раскладка (вкладки/ленты/контекст-кнопки), стратегические иконки с
  развед-гейтом, HP-полоски, плавающая миникарта, F11 — отладка.
- **Инфраструктура**: конвейер `tools/build.py` (линт + тесты + контроль версии/деплоя
  байтами), тест-раннер чистой логики.

## Сборка

```bash
python tools/build.py   # конвейер: пересборка (предупреждения = ошибки) + линт + тесты + проверка версии
```

По умолчанию DLL автоматически копируется в
`C:\Program Files (x86)\Steam\steamapps\common\Nuclear Option\BepInEx\plugins\SupremeNuclear\`.
Иная установка игры: `dotnet build -p:GameDir="X:\...\Nuclear Option"`.
Без деплоя: `-p:Deploy=false`.

Требуется .NET SDK (пакет reference-сборок net472 подтянется NuGet'ом автоматически).

**Релизы обновляются автоматически из master**: `python tools/publish.py` — снимок master →
публичная ветка main → релиз GitHub со свежим zip (требует `gh auth login`).

## Тест в игре

1. Запусти Nuclear Option (BepInEx 5 — уже стоит вместе с Ground Control).
2. Любая миссия с наземными юнитами (например, миссии Ground Control или своя из редактора).
3. Выйди из кабины (камера свободная) → **F10** — режим командира, **F10** — выход.
4. Горячие клавиши: ЛКМ — выделение/рамка/перетаскивание вейпоинтов (рамка без Shift:
   есть боевые юниты — выделятся только они, нет — все движущиеся; здания — кликом;
   Shift-рамка добавляет всё в порядке инженеры → логистика → оборонительные
   здания → производящие; клик по видимому чужому юниту или ракете — осмотр в инфопанели),
   ПКМ — приказ (Shift — серия; по союзному юниту — сопровождение/ассист),
   M/A/U/T/V/S — режимы (V — залп), R — атака веером
   (ПКМ по врагам копит цели, ПКМ по земле — раздать по целям), Alt+Shift+R —
   распределять очередь вейпоинтов группы прямыми векторами, G — на базу,
   H — огонь удерживать, Ctrl+1..9 — группы, Alt+1..4 — профиль высоты авиации,
   Shift+1..3 — скорость, Alt+D — авто-защита, X — ловушки, СКМ/колесо/Space (осмотр) —
   камера, F11 — отладка.

Настройки: `BepInEx/config/com.supremenuclear.rts.cfg`.
Баланс экономики: `BepInEx/plugins/SupremeNuclear/Economy/<профиль>.json` (образец создаётся сам).

## Известные ограничения

- **Мультиплеер**: командирский режим работает только у хоста (клиент-командир
  не заложен); гейты вооружения и whitelist станций залпа — тоже состояние хоста.
- **Флот** — самый свежий срез: палубная авиация CV/LHA, поведение T3-кораблей,
  снос недостроев и плавучесть Jackknife ещё не обкатаны плейтестами.
- Смена профиля высоты/скорости посреди Shift-серии патруля может создать
  «недостижимый» второй цикл (в разработке — [ARCHITECTURE §12](ARCHITECTURE.md#12-реестр-известных-долгов), долг 32).
- Диагностика (логи, SelfCheck, F11-оверлей) — только по-русски.
