# Supreme Nuclear (RTS)

**RTS в духе Supreme Commander для Nuclear Option.** Выйди из кабины, нажми **F10** —
и командуй с орбитальной камеры: рамочное выделение, очереди приказов с drag-редактированием
вейпоинтов, стройка где угодно, фабрики с производственными очередями (депо, аэродром,
верфь), своя ВПП, лодауты, патрули, эскорты и гейты вооружения.

[Скачать последний релиз](../../releases/latest) · `v0.98.1` · [MIT](LICENSE) · интерфейс **RU / EN**

Дизайн — [DESIGN.md](DESIGN.md) · устройство кода — [ARCHITECTURE.md](ARCHITECTURE.md) ·
правила изменений — [AGENTS.md](AGENTS.md).

## Установка (для игрока)

1. Установи BepInEx 5 в Nuclear Option (если ещё нет — так же, как для Ground Control).
2. Скачай `SupremeNuclear-<версия>.zip` из [релизов](../../releases) и распакуй в
   `Nuclear Option/BepInEx/plugins/` — должна получиться папка `SupremeNuclear`
   с DLL и `Locales/`.
3. В игре: выйди из кабины → **F10** — режим командира. Управление — раздел
   «Управление / Controls» ниже.

Сборка из исходников — спойлер «Разработчику».

## Quick start (English)

Play Nuclear Option as a Supreme Commander-style RTS: leave the cockpit, press **F10**.
Box-select units, right-click to order (Shift queues), drag-edit waypoints on the map,
build anywhere with engineers, run factories (vehicle depot / airbase / naval yard),
raise your own runway, pick aircraft loadouts, run patrols, escorts, missile salvos
and weapon gates. UI ships in English and Russian (`General.Language` in the BepInEx
config). Full controls — in the **Controls** section below (RU/EN).
Controls/UX feedback is welcome — GitHub Issues (feedback template).

## Известные ограничения

- **Мультиплеер**: командирский режим работает только у хоста (клиент-командир
  не заложен); гейты вооружения и whitelist станций залпа — тоже состояние хоста.
- **Флот** — самый свежий срез: палубная авиация CV/LHA, поведение T3-кораблей,
  снос недостроев и плавучесть Jackknife ещё не обкатаны плейтестами.
- Смена профиля высоты/скорости посреди Shift-серии патруля может создать
  «недостижимый» второй цикл (в разработке — [ARCHITECTURE §12](ARCHITECTURE.md#12-реестр-известных-долгов), долг 32).
- Диагностика (логи, SelfCheck, F11-оверлей) — только по-русски.

## Языки / Languages

Интерфейс мода локализован: **русский** (основной) и **английский** — настройка
`General.Language` в `BepInEx/config/com.supremenuclear.rts.cfg` (`auto` — язык системы,
принудительно `ru`/`en`; применяется при запуске). Добавить свой язык — один файл
`BepInEx/plugins/SupremeNuclear/Locales/<язык>.json` по образцу `en.json` (см. AGENTS
«Правила локализации»). Диагностика (логи, SelfCheck, F11) — только по-русски.

The mod UI ships in **Russian** (source language) and **English** — set
`General.Language` in the BepInEx config (`auto` follows your OS language). New locales
are a single JSON file; untranslated entries fall back to English, then Russian.

### Камера «взгляд из космоса» (SupCom)

СКМ — «схватить и тащить» карту (скорость 1:1 масштабу сцены, без лага сглаживания),
колесо — зум к курсору в обе стороны (до «вся карта в кадре», облака выше 15 км
скрываются). Наклон — одна гладкая кривая по зуму: из космоса — вид сверху, при
подъезде к поверхности плавно и слегка ужесточается до крутого взгляда в землю
(горизонта в обычной игре не видно). **Space (зажать) — осмотр**: мышью крутишь вид
вокруг точки в любую сторону, включая горизонт; отпустил — камера возвращается
(удобно снова обводить войска). Edge-scroll, Home — центр карты.
Floating origin зафиксирован на время режима (без дрожи мира); эффект Доплера гасится
(камера летает на скорости в тысячи м/с — без этого звук «пилит» уши; настройка
`Audio/CommanderNoDoppler`, вне режима звук штатный).

### Выделение

Клик, рамка, двойной клик — все юниты типа на экране; группы управления
Ctrl+1..9 / 1..9 (дабл-тап — камера на группу); клик по зданию аэродрома — выбор
аэродрома. Инфопанель группы показывает сводку вооружения: чем работать по целям
(теги АА/АЗ/У, ядерное — «Я»), заряд/ёмкость по группе и число носителей (две станции
на одном борту — один носитель), расстрелянные типы помечены «пусто»; грузовые/десантные
станции не считаются.

### Кольца дальности (SupCom)

У выделенных юнитов рисуются кольца **атаки по наземным** (красное) и **по воздушным
целям** (синее — максимум дальности станций соответствующего домена, разрешённых
гейтами вооружения), **разведки** (белое — радар/визуальный детектор юнита) и
**стройки** (охристое — инженерный радиус площадки). Рендер как в SupCom: векторные
полилинии в мире (ломаная видна вблизи), прибиты к земле идеально и не нагружают кадр;
вблизи камеры кольца следуют мешу поверхности точными высотами, на стратегическом
зуме — сглаженный кэш; видны сквозь сопки (абстракция стратегического слоя).
Переключатели «Назем / Воздух / Разведка / Стройка» — чипы под миникартой (цвет чипа =
цвет колец); всё выключить — «кинематографичный» экран без колец, выделение остаётся.
Режим **«Оружие»** (чип под миникартой): вместо доменных колец атаки — кольца по классам
вооружения (пушки жёлтые / ракеты ВВ синие / ракеты АС красные / бомбы и ЯЗ
фиолетовые), только по классам, разрешённым гейтами — выключил «Рак.АС» и видно,
что осталось (например, пушечный выхлоп из-за холма).

### Осмотр чужих целей

ЛКМ по видимому вражескому/союзному юниту, зданию или летящей ракете/бомбе —
инфопанель разведки (HP/скорость/высота под живым наблюдением, возраст протухшего
контакта; у ракет — двигатель, ГСН, БЧ и наша ли цель у ГСН). Видимость — как у иконок:
без разведки чужой не «прощупать», ракеты видны обеим сторонам; панель гаснет, когда
цель погибла или ушла из разведки.

### UI

SupCom-раскладка (вкладки/ленты/контекст-кнопки), стратегические иконки с
развед-гейтом, HP-полоски, плавающая миникарта, F11 — отладка.

<summary><b>Приказы и бой</b></summary>

### Приказы (ПКМ, Shift — очередь)

Движение решёткой-формацией, атака-движение, атака по цели (авиация и наземка/флот;
Shift+ПКМ по целям — серия: цели выполняются по порядку, у наземки/флота — очередь
целей), патруль (авиация и наземка/флот: цикл точек, ноги с боем; инженеры в патруле
сами достраивают близлежащие недострои и возвращаются в маршрут), залп, стоп;
drag-редактирование вейпоинтов прямо на карте, снап постановки к юнитам;
ПКМ по вейпоинту превращает сегмент плана борта в патруль, а маршрут наземки/флота —
в цикл. Авиация летает сегментами с профилями высоты/скорости, огибанием
рельефа, углы вейпоинтов скруглены (радиус — Routes/RouteCornerRadiusM); вертолёты и
тильтвинги исполняют приказы наравне с самолётами (своя перегрузка автопилота,
вертикальная посадка в цикле вылета).

### Сопровождение/ассист (ПКМ по союзному юниту)

Боевые следуют за целью своим сектором (группа распределяется по секторам вокруг), рядом
с целью защищают её — стоп-энд-файр (флот дерётся на ходу); **движение — плавно по
следу цели**: якорь эскорта скользит по сплайну (Catmull-Rom) её траектории на
дистанции позади — колонна повторяет маршрут цели без рывков; цель встала — охрана
собирается кольцом вокруг. Инженеры сопровождают и **вливаются в стройки цели** —
достроили её площадку и вернулись к сопровождению. Авиация сопровождает полётом
(держится у цели, враг в дальности вооружения — нативный бой; Shift+ПКМ — дописать
эскорт в план). Связь видна зелёной лентой к цели; Ctrl+Shift+ПКМ по цели снимает
сопровождение у всех, S/новый приказ — как обычно.

### Маршрутизация наземки

Наземка своих едет к цели напрямую (SupCom-стиль), не заезжая на шоссе ради коротких
перегонов; если прямая пересекает воду — маршрут строится по-нативному, через мосты
(отключается: Orders → GroundDirectRouting в конфиге).

### Панель команд и гейты вооружения

Состав кнопок — по типам войск в выделении (авиация получает ряды высоты/скорости/
защиты и чипы станций, наземка — только применимые приказы); внизу карточки — гейты
вооружения: кнопки ЯД/Бомбы/Пушки/Рак.ВВ/Рак.АС (по составу выделения) выключают класс
оружия всему выделению — выключенный класс не применяется ни автоогнём, ни в явной
атаке/залпе; подсветка — зелёный/красный/жёлтый.

### Атака по цели = гарантированный огонь доступными средствами

Борт пиннится на указанную цель (стройка цели в бой — нативный AI игры), подлетает
к ней по даталинку (нет контакта — к точке клика, сенсоры захватят по пути); ракетный
залп нативно распределяется по соседним целям. Атака-движение — конусом по вектору
приказа. Боезапас/топливо конечны: «сухой» борт уходит на базу, перевооружается/
заправляется (аэродромный сервис за деньги) и повторяет вылет, пока цель жива.
Наземка дерётся на ходу нативными турелями; атака-движение наземки — стоп-энд-файр
(заметил → встал → расстрелял → поехал дальше), атака цели — подход на дальность
вооружения.

### Посадка на указанную ВПП (ПКМ по полотну)

Выдели борта и кликни ПКМ по ПОЛОТНУ своей полосы (дефолтный режим «Движение») —
борта пойдут садиться НА ЭТУ базу: посадка, сервис и резерв ангара именно там.
Shift+ПКМ — посадка дописывается в хвост текущего плана (как Shift+G). Полоса
проверяется каждому борту (короткая полоса тяжёлому борту — Notice «ВПП не подходит»,
вертолётам нужны вертикальные точки); стоящий на ДРУГОЙ стоянке борт
перебазируется: выкат, перелёт, посадка у цели. G по-прежнему ведёт к ближайшей
открытой базе.

### «На базу» (G) = возврат в резерв ангара

Выделенные борта — пачкой или поодиночке, самолёты и вертолёты — возвращаются на
ближайший подходящий свой аэродром, садятся, обслуживаются (перевооружение/заправка
за деньги) и уходят **в резерв ангара** (деспавн): не занимают полосы и не висят
мёртвым грузом. Выкат — плиткой «РЕЗ ×N» в панели аэродрома (бесплатно, борт
выкатывается из ангара и взлетает). Резерв привязан к базе и теряется вместе с ней
при захвате. Боевой авто-возврат («сухой» борт) остаётся физическим: сел →
обслужился → взлетел → продолжил вылет.

### Залп по нескольким целям (V)

ПКМ по цели — подлёт и одновременный пуск выбранных ракетных станций (распределение
по соседним целям — нативное, расход по потребности, потолок ракет на цель —
настройка); ПКМ по земле — залп по площади у точки; Shift+ПКМ по целям — дописать цели
в один залп («разом по нескольким»). Выбор вооружения — чипами станций на панели
(одиночный борт). Бомбы/пушки — нативный бой. После залпа «сухой» борт сам идёт на
перевооружение и продолжает план.

### Распределение (R)

Выдели группу атакующих, заряди R, ПКМ по врагам накапливает цели (фиолетовые кресты
с номерами), ПКМ по земле — группа распределяется по целям: каждый атакующий берёт
ближайшую цель со свободной ёмкостью, раздача ровная без давки; атакующих меньше
целей — каждый берёт ближайшую свободную, дальние остаются. Авиация получает
атаку-вылет, наземка/флот — преследование; инженеры не воюют. Пустой список при
выдаче — деградация в атаку-движение.

### Групповое управление

Групповые вейпоинты — свойство приказа, а не выделения (один маркер на приказ у всей
группы, драг/удаление двигают всех — выделять всю группу не нужно); маршрут группы —
одна магистраль от центра юнитов через точки приказов, индивидуальные приказы — личные
ветки схождения/расхождения; shift+клик/рамка — добавление в группу. Alt+Shift+R —
рассредоточение (Disperse Move): очередь групповых вейпоинтов распределяется прямыми
векторами по юнитам (FAF-стиль); серия целей атак — по одной на юнита; серия площадок
инженеров — по кучкам (каждый строит свою часть серии).

### Стройка где угодно

Инженеры (грузовики/Jackknife), каталог с тирами, shift-серии, единая очередь инженера
по порядку кликов, кольцевой подход (инженеры окружают призрак и останавливаются

с уплаченным прогрессом — её подхватывают другие инженеры.

### Экономика v1 (хост)

Месторождения (авторазметка или JSON-профиль) + захватываемые экстракторы с тиями
T1–T3 и апгрейдами, тиковый доход во фракционные деньги.

### Покупки

Техника через депо, авиация через аэродром (панель по клику).

<summary><b>Фабрики, аэродромы, флот</b></summary>

### Фабрики с очередями

Депо и аэродромы — потоковая оплата, пауза/цикл, ралли-маршруты (точки двигаются
ЛКМ-драгом и удаляются Ctrl+Shift+ПКМ, как вейпоинты; у мультивыделения фабрик общий
маршрут правится разом), стак плиток с
прогресс-баром. **Недостроенная фабрика** (площадка депо/верфи/ангара) уже принимает
заказы: клик по площадке — каталог и очередь как у готовой, выпуск начнётся сам по
завершении стройки (снос площадки — очередь пропадает). Плитки читаемые: короткая
подпись борта (`code`), бейдж типа
слева-сверху (авиация — индивидуальный силуэт как на макрокамере и роль И/У/М;
наземка — ТНК/ББМ/АРТ/ЗРК/… по классу), у плиток каталога — цена; наведение на плитку
переключает левую панель свойств в карточку закупки (имя, класс/роль, цена и время,
ТТХ — обзор/скорость/броня/экипаж, вооружение) и открывает окно «ОПИСАНИЕ» под ней.

### Лодауты

**Колесо мыши** над плиткой авиации в каталоге циклит пресеты (Стандарт →
именованные; выбор липкий по типу борта, плитка помечает отступление «·ЛN», карточка
пересчитывает вооружение и показывает недоступные пресеты). **СКМ по плитке** — окно
«ОСНАЩЕНИЕ»: пресеты, топливо, станции с клик-циклом вариантов (правки = пресет
«Свой» в общем цикле), масса подвесок и легальность на аэродроме. Клики по стаку
очереди: ЛКМ — +1, ПКМ — −1 с возвратом денег, Shift — ±5.

### Своя ВПП и ангары

Аэродромная ёмкость наращивается стройкой: здания-ангары из каталога игры инженер
строит рядом со своим аэродромом, мод дорисовывает рулёжки и поверхность под них;
направление выката задаётся удержанием ЛКМ при постановке. **ВПП строится инженером**:
драг «торец → торец» (900–4000 м, реверсивная взлёт/посадка), по готовности — новый
захватываемый аэродром со своей очередью и своим гридом ангаров.

### Шаблоны («Ш»)

Персистентные JSON-наборы с относительными позициями зданий: применяются очередью
фабрики или призраками всех построек у курсора; заблокированные точки подсвечиваются
красным и пропускаются.

### Флот и верфь (v0.92)

Платформа-верфь на воде в духе SupCom — инженеры строят её посреди бухты (плавучий
Jackknife «барахтается» вплавь к площадке), готовая верфь — третья фабрика: очередь
кораблей с потоковой оплатой, тиры по цене (T1 катера → T3 авианосцы), спуск кольцами
в свободную воду с проверкой глубины и габарита, ралли-маршруты как у депо; корабли
(8 типов, включая палубные Hyperion CV с финишером и Annex LHA) водятся общим контуром
приказов.

**Авианосцы строят палубную авиацию (v0.108)**: выдели корабль — панель «Производство»
показывает его авиакрыло (каталог = юнион палубных ангаров; CV — палубные
самолёты/вертолёты, LHA — VTOL и лёгкие), заказ идёт «в самый свободный ангар»,
оплата — параллельно по палубным ангарам, борт выкатывается нативно — двери ангара,
скорость корабля, взлёт с трамплина. Вернувшиеся на корабль борта копятся в резерве
«РЕЗ» и выкатываются бесплатно; ралли спущенных бортов — **Ctrl+ПКМ** по земле при
выделенном корабле (замена маршрута; ПКМ без Ctrl — приказ самому кораблю), а кнопка
**«Авиакрыло»** в командной карте (паттерн SupCom «модуль корабля») переключает
выделение на аэродром корабля и обратно («Корабль») — там ПКМ = ралли с полным Shift
(дописывание), Пауза/Цикл действуют на все палубные ангары. Наземную
технику авианосец не производит — только авиация.

## Управление / Controls

<details>
<summary><b>Русский (RU)</b></summary>

- **ЛКМ** — выделение/рамка/перетаскивание вейпоинтов (рамка без Shift: есть боевые

  **Alt+Shift+R** — рассредоточить очередь вейпоинтов группы (Disperse Move); серия

- **Ctrl+1..9 / 1..9** — группы (дабл-тап — камера на группу)
- **Alt+1..4** — профиль высоты авиации; **Shift+1..3** — скорость; **Alt+T** —

- **СКМ/колесо** — камера (drag/зум к курсору); **Space (зажать)** — осмотр;
  **Home** — центр карты; **F10** — вход/выход из режима командира; **F11** — отладка
- Миникарта: ЛКМ — прыжок камеры, ПКМ — приказ, колесо при наведении — зум «в курсор»

### Инфраструктура

Каркас BepInEx-плагина; Harmony-патчи (руление авиации с приказом, пиннинг цели,
выбор аэродрома, наземный патфайндинг и др.) — все с честным откатом к штатному
поведению; полный реестр — ARCHITECTURE §6. Конвейер `tools/build.py` (линт + тесты +
контроль версии/деплоя байтами), тест-раннер чистой логики.

### Сборка

```bash
python tools/build.py   # конвейер: пересборка (предупреждения = ошибки) + линт + тесты + проверка версии
```

По умолчанию DLL автоматически копируется в
`C:\Program Files (x86)\Steam\steamapps\common\Nuclear Option\BepInEx\plugins\SupremeNuclear\`.
Иная установка игры: `dotnet build -p:GameDir="X:\...\Nuclear Option"`.
Без деплоя: `-p:Deploy=false`.
Требуется .NET SDK (пакет reference-сборок net472 подтянется NuGet'ом автоматически).

**Релизы обновляются автоматически из master**: `python tools/publish.py` — снимок
master → публичная ветка main → релиз GitHub со свежим zip (требует `gh auth login`).

```
src/SupremeNuclear/

  CameraRts/                 — CommanderCameraState (стратегическая камера, без патчей)
  Input/                     — RtsInput: сырой ввод с защитой от чата
  ...
```
