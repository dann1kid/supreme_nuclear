# AGENTS.md — правила работы с кодовой базой Supreme Nuclear

RTS-мод (BepInEx, C#/.NET Framework 4.7.2) для Nuclear Option в духе Supreme Commander.
Язык проекта — **русский**: комментарии, логи, диагностика, документация.
Игроковые строки (UI/Notice/описания настроек) — русским литералом в коде через
`Loc.Tr/F/Plural` (gettext: русская строка = ключ; перевод — `locales/<язык>.json`,
en — фолбэк; см. «Правила локализации» ниже).

## Перед любым изменением кода

1. Прочитай **ARCHITECTURE.md** — минимум §3 (порядок тиков), §4 (владение состоянием),
   §7 (инварианты), §10 (рецепт твоей задачи). Это as-built карта; расхождение кода
   с документом — баг документации, исправь его тем же коммитом.
2. Гейм-дизайн и план — **DESIGN.md**. Не изобретать механики, противоречащие зафиксированным
   решениям (§2); открытые вопросы — из §3, не решать молча.
3. Незнакомый игровой API сверяй с `decompiled/` (декомпилированная игра). `GroundControlRts/` —
   только референс, **код не копировать** (лицензия).

## Сборка и проверка

- ВЕРСИЯ в `PluginInfo.cs` правится ТОЛЬКО инструментом Edit (не python/bash-скриптами:
  бамп версии тихо проваливался из-за кавычек — версия застряла на 0.35.2 на полдня).
  Любая python-замена кода обязана `assert old in s` перед записью и проверять счётчик замен.
- «0 ошибок / 0 предупреждений» проверять на ПОЛНОЙ пересборке (`rm -rf obj` перед build):
  инкрементальная сборка прячет предупреждения (CS0649 и т.п.).

```bash
python tools/build.py        # полный конвейер: clean-сборка (warnaserror) + линт + тесты + проверка версии/деплоя
python tools/build.py --fast # без чистки obj
```

- Конвейер обязан быть ЗЕЛЁНЫМ: clean-сборка **0 ошибок / 0 предупреждений** (-warnaserror),
  линт (двойной Text; GameObject без RectTransform; застрявшая версия), локали
  (`tools/check_locales.py`: ключи `Loc.*` в коде = ключи каждого `locales/*.json`),
  тесты чистой логики
  (`tests/`, консольный раннер), версия из PluginInfo найдена в bin И в задеплоенном DLL
  байтами, bin == игровой DLL, `locales/*.json` в игре идентичны репозиторию. DLL и локали
  деплоятся в игру автоматически
  (отключить: `-p:Deploy=false`, другая папка игры: `-p:GameDir="..."`).
- «Тест в игре» делает пользователь; от агента — чистая сборка и отсутствие регрессов по §7.
- Изменил видимое поведение/фичи — подними минорную версию в `PluginInfo.cs`.

## Жёсткие правила (нарушение = баг)

1. **Floating origin**: долгоживущие мировые точки — только `GlobalPosition`
   (`ToGlobalPosition()/ToLocalPosition()`), локальный `Vector3` протухает (сдвиг ≥1024 м).
2. **Host-only**: деньги (`AddFunds`), спавн, апгрейды — только при
   `NetworkManagerNuclearOption.i.Server.Active`. Клиенту — лишь приказы
   `UnitCommand.SetDestination(..., playerCommand: true)`.
3. **Harmony-Prefix обязан возвращать `true`**, если мод не берёт управление. Реестр патчей —
   ARCHITECTURE §6; новый патч — крайняя мера, сначала композиция.
4. **Приказы/игровые действия — только по событиям ввода** (`RtsInput`), никогда «на каждый кадр».
5. **Порядок тиков не трогать**: `RouteEditor.Tick` строго до `Selection.Tick`;
   оркестратор один — `CommanderModeController.Update` (ARCHITECTURE §3.2).
6. **Ввод — только через `RtsInput`** (там защита от чата `Typing` и `PointerOverUi`).
7. **Кэши инвалидируются Version-счётчиками** (`AircraftOrders.Version`, `GroundOrders.Version`),
   не таймерами/флагами. Драг/удаление вейпоинтов бампит их через API сервисов.
8. **`OnGUI` вызывается 2+ раза за кадр** — без аллокаций и мутаций состояния на вызов.
9. **Парность Enter/Leave** (камера: farClip, порог FloatingOrigin, TrackIR, облака) —
   что изменил на входе, восстанови на всех путях выхода, включая тихие.
10. **UI-разделение**: мировой оверлей (иконки/кольца/маршруты) → `CommanderHud` (IMGUI);
    экранные панели/кнопки → `SupcomUi` (uGUI).
11. **Статическое состояние** (словари планов/групп/стойк) переживает сцены — новое статическое
    состояние сбрасывай в `sceneLoaded` (см. `SupremeNuclearPlugin`), реестр состояния — ARCHITECTURE §4.
12. **Балансные числа — в JSON/Settings**, не в коде (профиль экономики: `EconomyProfile`).
13. Новое предположение об API игры — добавь проверку в `SelfCheck`.
14. Каждый `Unit` из долгоживущих коллекций перед использованием проверять на
    `null`/`disabled` (Unity fake-null!) — и не доверять `Selected` без prune.
15. **Текст uGUI**: никогда не совмещать `typeof(Text)` в конструкторе GameObject с
    `AddComponent<Text>()` — двойной Text даёт NRE в рантайме (дважды подтверждено:
    FloatingWindow, StripArrows). Либо только ctor (паттерн `Label`), либо только
    `AddComponent` после `RectTransform`. Аналогично осторожно с любым UI-компонентом
    в ctor + AddComponent.
16. **`Graphics.DrawMesh` — только из Update (до рендера)**; из OnGUI — мерцание.
17. **Призраки/превью = DrawMesh-силуэты (модель GC)**, НЕ Instantiate юнит-префабов:
    Awake/реестр/физика/материалы дают серии багов. Материал — встроенный
    `Hidden/Internal-Colored`; части с null-материалами не рисовать (маджента).
18. **uGUI-драг в этой игре не работает** (игровой input-модуль не доставляет
    `IBeginDragHandler/IDragHandler`): перетаскивание строить из `IPointerDown/Up` +
    опрос в `Update`; кликом считать нажатие без движения (<6 px).

## Правила консолидации (v0.48, вейпоинты расширены v0.89) — дубликаты не заводить

- **Вейпоинты**: поиск «что под курсором» — ТОЛЬКО через `WaypointScanner.Scan`
  (захват драга, удаление, конвертация в патруль; тело 3D-призрака площадки сканер
  отдаёт как `BuildSite`; единый пик-радиус `PickPx`). Действие над найденным —
  ТОЛЬКО через фасад `WaypointOps` (`DeleteAt`/`ConvertToPatrolAt`/`Move`).
  Новый вид вейпоинта = новый `WaypointKind` в сканере + ветки в `WaypointOps`,
  а не копия цикла сканирования/свитча у себя.
- **Члены группы приказа** — только через `CollectGroup`-примитивы сервисов
  (`GroundOrders`/`AircraftOrders`/`BuildTasks`, сигнатуры зеркальны): их зовут
  и групповое удаление (`WaypointOps.DeleteAt`), и групповой драг (`RouteEditor`).
- **Правила-пропуски живут у владельцев данных**: «служебная авиаточка» —
  `AircraftOrders.IsServicePoint` (сканер + маркеры), «цепочка инженера —
  выданная голова» — `BuildTasks.ChainIsIssuedHead` (сканер + HUD + меш-лента).
- **Планы авиации мутруются только через API `AircraftOrders`** (голова —
  `DropHeadSegment`/`InsertHeadSegment` для SortieService), не кастом списка.
- **Иконки юнитов (IMGUI)**: отрисовка спрайта — только `CommanderHud.DrawUnitSprite`
  (центр/размер/спрайт/тинт/тень); ориентированные силуэты авиации — отдельно
  (`DrawOrientedSprite`).
- **Плитки UI 48×48** (очереди/наборы/каталог): только `SupcomUi.Tile` (+`TileClicks`
  для ЛКМ/ПКМ). Новый бейдж/бар — параметром в Tile, не новой копией плитки.
- **Чистая логика** — в `Core/Util.cs` / `UiRts/Catalog.cs` (без Unity-вызовов) + тест
  в `tests/`. Юнит-зависимая логика остаётся в сервисах.
- Правило зеркальности: если правишь один из парных методов (например, удаление
  вейпоинтов) — проверь, что второй (захват) не должен получить то же изменение:
  теперь они на одном сканере.

## Правила локализации (v0.93) — игроковые строки через `Core/Loc.cs`

- **Исходник = ключ (gettext)**: русская строка пишется литералом в коде и оборачивается
  `Loc.Tr("...")` (простая) / `Loc.F("... {0}", x)` (с подстановками — только номерные
  плейсхолдеры) / `Loc.Plural(n, "тип", "типа", "типов")` (формы множественного числа).
- **Локаль = JSON** `locales/<язык>.json` вида `{"_plural": "en", "русская строка": "перевод"}`.
  Русской локали-файла НЕТ (ключ = текст); en — фолбэк для прочих. Фолбэк-цепочка:
  выбранная локаль → en → русская исходная строка.
- **Новая локаль** = один JSON-файл в `locales/` (имя файла = значение настройки
  `General.Language`; допустимые значения собираются из папки при старте). Чекер
  конвейера перечислит недостающие ключи; `python tools/check_locales.py --fill-en`
  автодобивает en.json словарными состояниями (en-значение = английский оригинал-ключ).
  Плюрализация: `"_plural": "en"` — две формы ("one|other"), иначе русское
  правило трёх форм.
- **Что локализуется**: панели/кнопки/тултипы SupcomUi, маркеры/подсказки CommanderHud,
  Notice-сообщения сервисов, заголовки MinimapPanel, описания настроек (`Settings.Bind`
  — читай язык ДО Bind через `Settings.BindLanguage` + `Loc.Bootstrap` в Awake).
- **Что НЕ локализуется (русский навсегда)**: комментарии, логи `Log.*`, SelfCheck,
  F11-диагностика (`LastClickDebug`/`LastGrabDebug`/оверлей отладки) — инструменты
  разработчика (долг ARCHITECTURE §12-32).
- Составные строки не склеивать из переводимых кусков: вся фраза — один ключ
  с `{0}`-плейсхолдерами (порядок слов в других языках другой). Суффиксы-частицы
  (`" · пусто"`) допустимы как отдельные ключи только когда они условные метки.
- Состояние `Loc` конфигурационное: загружается в `Awake` ДО `Settings.Bind`,
  `sceneLoaded` его не трогает; смена языка применяется при перезапуске игры.
